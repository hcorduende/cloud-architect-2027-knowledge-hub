AZ-104 — Azure Administrator Associate

Validate practical administration of Azure identities, governance, storage, compute and networking.

Study domains

Manage identities and governance; implement storage; deploy and manage compute; configure virtual networking; monitor and maintain Azure resources.

Hands-on preparation

Build a resource group, VNet and subnets, NSGs, VM, storage account, Azure Monitor alerts and role assignments. Document the security decisions.

Exam readiness

Practice scenario questions and verify you can perform common administration tasks in the Azure portal, CLI or PowerShell.
